# 🚙 Carwash Tycoon

Een Nederlandstalige mobile-first carwash-managementgame. Speel direct in je browser: start een klant, was met je vinger de vuilplekken van de auto, verdien geld en investeer in upgrades.

## Starten
Open `index.html` lokaal of publiceer de repository via **Settings → Pages → Deploy from a branch → main → /(root)**.

Na publicatie: https://theroyalcaptain.github.io/Carwash-Tycoon/

## Gameplay
- Touchscreen en muis
- Verschillende auto's en wasprogramma's
- Hogedrukreiniger, shampoo, reclame en personeel
- Omzet, reputatie en levelprogressie
- Voortgang in `localStorage` (per browser/apparaat)

## Techniek
Zelfstandige HTML/CSS/JavaScript-game zonder buildstap, dependencies of backend. Daardoor geschikt voor GitHub Pages.
